# 实时聊天服务

## 概述

基于Linux平台，采用TCP套接字、C语言多线程技术开发，采用服务器-客户端（C/S）架构。服务器主线程监听客户端连接，每接入新客户端就创建独立子线程处理通信；系统仅实现用户私聊，不支持群聊；程序利用链表维护在线用户信息与离线私聊消息，使用用户名与密码作为用户唯一标识。支持用户离线重新识别、离线消息缓存，用户重新登录后自动接收未读信息。

## 技术架构

### 服务器

服务器监听，等待客户端连接，每来一个客户端请求，就创建一个子线程处理请求

```c
// 服务器
#include "my.h"

User user[UMAX]; // 用户信息
int unumber = 0; // 已存用户数量
OnList onlist; // 在线用户链表
OffList offlist; // 离线消息链表

int main(int argc, char const *argv[])
{
    // 初始化链表
    onlistinit(&onlist);
    offlistinit(&offlist);
    // TCP套接字
    int fd = socket(AF_INET, SOCK_STREAM, 0);
    // 地址复用
    int opt = 1;
    setsockopt(fd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    // 创建服务器地址
    struct sockaddr_in saddr;
    memset(&saddr, 0, sizeof(saddr));
    saddr.sin_family = AF_INET;
    saddr.sin_port = htons(9000);
    saddr.sin_addr.s_addr = htonl(INADDR_ANY);
    // 绑定地址
    bind(fd, (struct sockaddr *)&saddr, sizeof(saddr));
    // 监听
    listen(fd, 9);
    printf("服务器启动\n");

    while (1)
    {
        // 存储客户端地址
        struct sockaddr_in caddr;
        memset(&caddr, 0, sizeof(caddr));
        int len = sizeof(caddr);
        // 建立TCP连接
        int c_fd = accept(fd, (struct sockaddr *)&caddr, &len);
        if (c_fd < 0)
        {
            perror("服务器 accept() 调用失败\n");
            continue;
        }
        pthread_t t;
        pthread_create(&t, NULL, server_task, &c_fd);
        pthread_detach(t);
    }

    return 0;
}
```

## 业务完整流程

- 启动服务器，持续监听
- 运行多个客服端，建立TCP连接并上传用户名与密码完成登录
- 客户端输入 @用户名 消息 发送；客户端封装协议发送至服务器
- 服务器查询目标用户是否存在或者在线状态，不存在返回不存在，在线直接发送，离线缓存消息，
- 目标客户端下线再次登录，服务器自动补发全部缓存的离线消息
- 客户端退出，断开连接，服务器是否套接字与链表资源
